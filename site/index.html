~/skillori/what-it-does6 items

  1. It tattles

    When a source changes, the menu bar icon changes colour. Subtle, but it knows.

    01

  2. It updates

    One click runs the update. You get to watch the terminal do the typing.

    02

  3. It finds

    Every skill on your Mac, whichever agent it lives with and however it got there.

    03

  4. It traces

    Each skill back to its source repo, down to the exact revision. Receipts included.

    04

  5. It adopts

    Found a skill with no known source? Link one, and it’s tracked like the rest.

    05

  6. It shares

    Pick a few skills and get one command a friend can paste into a terminal or an agent. They don’t need Skillori to run it.

    06

Changelog

Privacy, in full: Skillori has no account and no trackers. Once a day it asks skillori.app whether there’s a new version (you can turn that off). If you turn on source checks, it asks GitHub one question per source. Downloads from this site are counted as a number, nothing more.

Agent names belong to their owners. Skillori isn’t affiliated with any of them. It just reads their folders.
