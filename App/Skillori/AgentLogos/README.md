# Agent logos

Logos for agents that have no app on this Mac to take an icon from. `AgentMark` looks for
`agent-<agent id>.png` here and falls back to a tile with two letters.

The PNG files are **not committed**. They are other companies' marks, and their brand
guidelines have not been read yet. Sources are listed in
`docs/design/visuell-riktning-readout-2026-11-12.md`.
