# Fonts

Font files in this folder are registered at launch by `SkilloriFonts.register()`.

| File | Role | Source | Licence |
|---|---|---|---|
| `Inter.ttf` (variable) | Names and text | github.com/google/fonts, `ofl/inter` | SIL OFL 1.1, see `Inter-OFL.txt` |
| `GeistMono.ttf` (variable) | Labels, data, buttons | github.com/google/fonts, `ofl/geistmono` | SIL OFL 1.1, see `GeistMono-OFL.txt` |
| `icomoon.ttf` | Big numbers (dots) | Supplied by the product owner | Free to use, according to the product owner. No licence text on file. |

If a file is missing, its role falls back to the system sans or the system mono.
