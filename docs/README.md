# Docs

Skillori's working documents. They are written in Swedish and kept as history: rejected directions stay, so the reasons behind the current choices can be traced.

| Folder or file | What's there |
| --- | --- |
| [`Skillori-produktbrief.md`](Skillori-produktbrief.md) | The original product brief (working name Skillwatch): goals, principles, status model, stages |
| [`Skillori-namn-och-varumarkesbrief.md`](Skillori-namn-och-varumarkesbrief.md) | The name and the origami direction |
| [`backlog.md`](backlog.md) | What's done and what's next, per stage |
| [`beslut/`](beslut/) | Architecture decision records (ADR) |
| [`research/`](research/) | Compatibility matrix per agent, local inventory, technical spike |
| [`design/`](design/) | Visual explorations by date, renders of the native app, typography, references |
| [`images/`](images/) | Images used by the main README |

To look at the HTML studies in `design/`, open them straight from disk or serve the folder:

```bash
python3 -m http.server 4173 --directory docs/design
```
